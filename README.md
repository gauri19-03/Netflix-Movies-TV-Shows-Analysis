# Netflix Movies & TV Shows Analysis

## About the Project
This project explores Netflix movies and TV shows using Python libraries.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and missing-value analysis
- Movies vs TV Shows comparison
- Content ratings analysis
- Top 10 genres and countries
- Release-year trends
- Movie duration and TV show seasons

## How to Run

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Open `Netflix_Analysis.ipynb` in Jupyter or VS Code.
5. Place the dataset in the project folder, following the dataset source instructions.
6. Run the notebook cells in order.
